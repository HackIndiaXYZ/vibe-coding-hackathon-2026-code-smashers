Startup Autopsy

Every failed startup left clues. We found them.

Startup Autopsy is an AI-powered startup intelligence platform that helps founders evaluate ideas before they spend months building them.

Instead of generic business advice, Startup Autopsy compares your idea against real startup successes and failures, identifies historical patterns, and generates actionable insights using AI.

Built for HackIndia Vibe Coding Hackathon 2026.



The Problem

Every year thousands of startups fail because founders unknowingly repeat mistakes that have already been made before.

Questions every founder asks:

 Has someone tried this idea before?
 Why did similar startups fail?
 What made others succeed?
 What risks am I not seeing?

Finding those answers normally requires hours of research.

Startup Autopsy does it in seconds.

 What It Does

Enter your startup idea in plain English.

Example:

 "AI-powered tutor for school students"

Startup Autopsy will:

 Find similar successful startups

 Find similar failed startups

 Analyze historical patterns

 Calculate survival probability

 Highlight major risk factors

 Generate AI-powered recommendations

Visualize results with interactive charts



Features

 AI Startup Analyst

Powered by Gemini AI to generate intelligent startup assessments.

 Startup Graveyard

Learn from startups that failed before making the same mistakes.

 Startup Survivors

Discover companies that successfully executed similar ideas.

 Survival Probability Engine

Estimate the chances of success using historical startup patterns.

Risk Detection

Identify business model, market, and execution risks early.

 Cloud Database

Startup records stored and queried using Supabase.

 Dynamic Visualizations

Interactive charts update in real time based on analysis results.

 How It Works

1. User enters a startup idea.
2. Keywords are extracted.
3. Similar startups are retrieved from the database.
4. Gemini analyzes the results.
5. Survival probability and risks are generated.
6. Insights are displayed through charts and recommendations.



Why We Built This

Founders don't need more startup advice.

They need startup evidence.

Startup Autopsy transforms startup history into actionable intelligence by learning from both the winners and the graveyard.
